# Close Plan Generator — Tips & Best Practices

> Extracted from SKILL.md — content preserved verbatim.

**For Phil Sandler & Lex Evans:**

1. **Run Early, Run Often:**
   - Generate close plan at "Negotiation" stage, not at final signature push
   - Re-run weekly to track confidence drift and risk changes
   - Update MEDDIC roles if new stakeholders surface (e.g., unexpected legal review)

2. **Stakeholder Mapping is Everything:**
   - If you can't name all decision-makers (EB, Champion, Coach, Blockers), you don't have enough discovery
   - Champion engagement (8+ on 0-10 scale) is the #1 predictor of close likelihood
   - EB disengagement is a red flag—address in this-week actions immediately

3. **Use Clari Objections to Drive Actions:**
   - If judge is skeptical of learning curve → schedule simplified demo
   - If legal counsel is blocking → pre-circulate SOW and compliance doc
   - If budget gatekeeper questions ROI → send customer reference from similar company

4. **Confidence Score is Diagnostic, Not Predictive:**
   - Score drops = take action, don't panic
   - Focus on the two lowest-scoring components (MEDDIC gaps, momentum, competitive position)
   - 65+ is usually closeable; <55 needs reset or new champion

5. **Mutual Action Plan = Prospect Accountability:**
   - Share in every meeting from Negotiation onward
   - Include prospect commitments (budget approval, legal review, eval completion) with deadlines
   - Follow up in next email: "Per our action plan, are we on track for [date]?"

6. **Coordinate with Tim (BDR):**
   - If close plan surfaces new discovery gaps (e.g., no coach identified), loop Tim in
   - Tim can run competitor intel or champion reference calls
   - Use ae-handoff-brief context as starting point for Stage 1 discovery

7. **Reference Customer Calls = Objection Killer:**
   - When risk register surfaces objection (learning curve, incumbent defense, budget anxiety)
   - Request reference call with customer in similar vertical facing same concern
   - Schedule in this-week actions with SE if needed
