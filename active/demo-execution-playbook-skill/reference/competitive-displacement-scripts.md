# Demo Execution Playbook — Competitive Displacement Scripts

> Extracted from SKILL.md — content preserved verbatim.

**vs. Extron SMP:**
"Extron SMP was discontinued in 2022. If your current SMP fails, there's no vendor support or replacement parts. Pearl-2 is actively developed, with security patches every quarter and new integrations every release. Plus, Pearl adds cloud recording and management—SMP was on-prem only."

**vs. Blackmagic ATEM + Recorder:**
"Blackmagic ATEM requires a control operator in a control room—someone switching scenes live. Pearl auto-switches between inputs and records unattended. So ATEM is a live-switch tool for broadcast; Pearl is a capture-and-publish tool for education/enterprise. If you need a live operator, ATEM wins. If you want hands-off recording, Pearl wins."

**vs. Crestron:**
"Crestron is AV routing and control—it switches inputs and manages your room. It doesn't record or publish video. So Crestron + Blackmagic recorder + cloud platform = 3 vendors. Pearl records + publishes + manages—one vendor, one support contract, integrated API."

**vs. vMix:**
"vMix is software that runs on a Windows PC. It requires someone to open vMix, click record, manage scenes, etc. Pearl is a hardware appliance. Hit one button, it records and publishes automatically. vMix is for live events with an operator; Pearl is for unattended capture in classrooms/courtrooms/conference rooms."

**vs. Teradek:**
"Teradek is cloud-first streaming. All your data goes to their cloud. If your cloud connection drops, your stream stops. Pearl records locally to SSD—if cloud fails, you keep recording. Plus, Teradek doesn't have local failover or compliance-grade archival. Pearl does both."

**vs. Matrox (legacy):**
"Matrox exited the market. No new development, no security patches, no vendor support. Pearl is the modern replacement—same hardened recording spec, plus cloud management, plus active vendor support. Your Matrox will fail; we have a replacement strategy."
